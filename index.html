बुकिंग cancel कैसे करें?

मेरी बुकिंग में booking ID चुनकर Job Chat से provider या support को तुरंत संपर्क करें। इस demo में self-service cancellation/refund उपलब्ध नहीं है; support team से cancel request दर्ज करें।

Payment कट गया पर booking नहीं हुई तो क्या करें?

यह demo किसी असली online payment को process नहीं करता। असली app में payment reference ID संभालकर support chat में booking ID सहित शिकायत भेजें—इस demo में सीधे Report / Complain इस्तेमाल करें।

सर्विसमैन देर से आए तो क्या करें?

Booking के Job Chat से provider को संपर्क करें या Report / Complain में “Provider समय पर नहीं आया” चुनें। शिकायत Admin dashboard में alert होगी।

काम खराब हो या ज्यादा पैसे माँगे जाएँ?

Job Chat और invoice सुरक्षित रखें, अतिरिक्त payment न करें जिस पर सहमति न हो, और booking पर Report / Complain भेजें। Admin work-stream की समीक्षा कर सकता है।

सेवा लेने या देने के लिए अपने खाते में प्रवेश करें।

या
असली Google / ईमेल login के लिए अपनी Firebase Web App config जोड़ें। अभी demo mode उपलब्ध है।
Firebase login कैसे चालू करें? Firebase Console में Web App बनाएँ। Project settings → Your apps से apiKey, authDomain, projectId और appId को इस file में FIREBASE_CONFIG के YOUR_ placeholders से बदलें। Authentication → Sign-in method में Google और Email/Password चालू करें और Authentication → Settings → Authorized domains में अपनी website का domain जोड़ें। Website को localhost या HTTPS पर खोलें; file:// से Google popup काम नहीं करता। Firebase Web config browser में दिखती है—Service Account key कभी यहाँ न डालें।

डेमो मोड में असली account verification नहीं होती। पासवर्ड browser में सेव नहीं किया जाता।
